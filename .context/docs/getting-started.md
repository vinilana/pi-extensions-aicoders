## Local Pi Loading

- Load locally with `pi -e .` to test package extensions from `package.json`.
- Extension entrypoints: `./extensions/*.ts`, `./extensions/*/index.ts`.
- Theme paths: `./themes`.
- After `/dotcontext init`, run `/reload` so generated skills are discovered.
